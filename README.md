# 코드온 부스 안내 (CODE:ON)

2026학년도 동아리 발표회 코드온 부스용 웹앱입니다.
직접 학습시킨 신경망 챗봇과 3D 컴퓨터실 지도가 한 화면에서 함께 움직입니다.

## 실행

`index.html` 을 더블클릭합니다. 설치도 인터넷도 필요 없습니다. (Chrome 또는 Edge 권장)

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대 |
| `css/style.css` | 화면 꾸밈 |
| `js/data.js` | 행사, 좌석 구역, 팀 소개, 자리 배정 **(내용을 고칠 때 여는 파일)** |
| `js/intents.js` | 챗봇 학습 자료: 의도별 질문 예시 |
| `js/nlp.js` | 자연어 처리: 개체 찾기, 글자 조각 특징, 신경망 계산 |
| `js/chatbot.js` | 의도에 맞는 답 만들기 |
| `js/model.js` | 학습된 신경망 가중치 (자동 생성, 직접 고치지 않음) |
| `js/map3d.js` | 3D 컴퓨터실 지도 |
| `js/app.js` | 채팅창, 안내 창, 자리 배정 창 등 화면 연결 |
| `train.js` | 신경망 학습 스크립트 |
| `tests/questions.js` | 챗봇 시험 문제 (학습에 쓰지 않는 질문과 정답) |

## 자주 하는 수정

**팀 소개 문구 고치기**: `js/data.js` 의 `teams` 에서 `desc`, `how` 를 고치고 새로고침(F5).
지금 문구는 계획서의 주제만 보고 적은 임시 문구입니다.

**자리 배정 바꾸기**: 화면 오른쪽 위 `자리 배정` 버튼 (또는 Ctrl + Shift + E).
바꾼 내용은 그 브라우저에만 저장됩니다. 다른 컴퓨터로 옮기려면 창 아래의 코드를 복사해
그 컴퓨터의 같은 창에 붙여넣고 `코드 적용` 을 누르거나, `js/data.js` 의 `assignment` 를 그 코드로 바꿉니다.

**1부 → 2부 자동 전환**: `js/data.js` 의 `partSwitchTime` 에 교대 시각을 `"10:30"` 처럼 적습니다.
행사 날짜(12월 24일)에만 동작합니다. 비워 두면 화면의 1부/2부 버튼으로 바꿉니다.

**챗봇이 못 알아듣는 질문 가르치기**
1. 화면의 `작동 원리` 를 켜면 맨 아래에 "못 알아들은 질문" 개수와 `복사` 버튼이 있습니다.
2. 그 질문을 `js/intents.js` 의 알맞은 의도에 예시로 추가합니다.
3. 터미널에서 `node train.js` 를 실행합니다. (외부 패키지 없음, 약 20초)
4. 새로고침하면 새 모델이 적용됩니다.

팀의 `aliases`(다르게 부르는 이름)를 고쳤을 때도 `node train.js` 를 한 번 실행하세요.

**자동 초기화 시간**: `js/app.js` 맨 위 `IDLE_RESET_MS` (기본 2분, 0 이면 끔).

## 챗봇이 답하는 과정

1. 개체 찾기: 팀 이름, 진로 분야, 주제어를 찾아 기호(Ⓣ Ⓕ Ⓖ)로 바꿉니다. 자모 단위 비교로 오타도 어느 정도 잡습니다.
2. 특징 추출: 문장을 글자 1~3개짜리 조각(n-gram)으로 쪼개 숫자 벡터로 만듭니다.
3. 신경망: 입력 → 은닉층 64 → 은닉층 32 → 의도 35개의 확률(softmax). Adam, 드롭아웃으로 학습했습니다.
4. 개체 보정: 팀 이름이 없는데 "팀 위치" 의도가 나오면 낮추는 식으로 확률을 맞춥니다.
5. 확신도가 42%보다 낮으면 "배우지 않은 내용"이라고 답하고 그 질문을 기록합니다.

## 노트북에서 느릴 때

Windows 설정 → 시스템 → 디스플레이 → 그래픽에서 브라우저를 "고성능(외장 그래픽)"으로 지정하고 전원을 연결하세요.
계속 느리면 앱이 스스로 그림자를 끄고 해상도를 낮춥니다.
